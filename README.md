# GRAVEDAD CERO — sitio para GitHub Pages

Sube todos los archivos y carpetas al repositorio.

## Imágenes
Todas las fotos se cambian desde `assets/images/`.
El código ya usa nombres concretos. Puedes reemplazar una foto manteniendo el mismo nombre:
`portada.jpg`, `escalada.jpg`, `montana.jpg`, `trailrunning.jpg`, `ingenieria.jpg`, etc.

## Vídeos
Sube MP4 a `assets/videos/`. En `cursos/index.html` cambia el nombre del archivo dentro de `<source>`.

Para vídeos grandes se recomienda YouTube/Vimeo y luego insertar su enlace.

## Documentos
Sube PDFs a `assets/documents/` y cambia el enlace en el HTML.

## GitHub Pages
Repositorio público → Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Nota sobre comunidad y pagos
GitHub Pages es un sitio estático. Para cuentas de usuarios, publicaciones, comentarios, base de datos y pagos automáticos habrá que conectar servicios externos. Esta versión deja preparada la estructura y los botones de contacto.
